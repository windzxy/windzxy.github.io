# Windzxy HTML Tools

一套採用 Windzxy 品牌風格、可直接在瀏覽器開啟的日常辦公工具，無須安裝或啟動伺服器。支援淺色／深色模式，並會記住使用者選擇。

## 使用

可直接透過 `https://windzxy.github.io/Html_tools/` 使用，也可以下載此資料夾後雙擊 `index.html`。所有資料均在本機瀏覽器中處理，不會上傳。

## 線上使用

此 repo 已加入 GitHub Pages 靜態站入口與部署 workflow。啟用 Pages 後，預期網址為：

- `https://windzxy.github.io/test/`
- `https://windzxy.github.io/test/Html_tools/image-tool.html`

如果第一次尚未顯示，請到 GitHub repo 的 `Settings → Pages`，在 `Build and deployment` 的 `Source` 選擇 `GitHub Actions`，再到 `Actions` 執行或等待 `Deploy Windzxy HTML Tools`。

## 工具

- `image-tool.html`：圖片高保真/像素無損放大、本機去背、透明裁切、調色、壓縮與 JPG／PNG／WebP 轉換
- `text-tool.html`：文字統計、清理、去重、排序及大小寫轉換
- `table-tool.html`：CSV／TSV 貼上預覽、搜尋、複製與匯出
- `date-tool.html`：日期間隔、日曆天及工作天推算
- `json-tool.html`：JSON 格式化、壓縮與驗證
