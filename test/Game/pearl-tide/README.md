# 潮汐珠寶屋 · Pearl Tide

原創、繁體中文、響應式 HTML5 海邊珍珠經營遊戲。參考《阿珠開蚌直播間》的「買蚌 → 開蚌 → 珍珠 → 工坊 → 訂單 / 售賣」遊戲循環，但使用獨立名稱、介面、文案及數值，不搬運參考作品的程式碼或資產。

## 玩法

1. 開局 1,200 金、每天 6 行動力。漁市有四種價位與稀有度加成不同的貝殼；高價貝也有空貝風險。
2. 選擇安全開口：從中央貝縫切入可避免操作導致的表面微瑕；左右切入有刮傷風險。
3. 珍珠有六種顏色、五種稀有度、尺寸與微瑕特徵；每枚有獨立估值。
4. 工坊用 1 / 2 / 3 顆珍珠製作吊墜 / 耳環 / 項鍊；訂單按固定報酬收購，直播銷售依聲望得到小幅加價。
5. 結束營業恢復當日行動力；本地存檔自動寫入 localStorage，另可匯入與匯出 JSON。

## 雲端和排行榜（須由網站持有人啟用）

GitHub Pages 只提供靜態網站，不能單獨承載安全的跨裝置雲存檔或共享排行。本專案已接入可選 Supabase JS v2 客戶端與 RLS SQL，但**預設未配置，因此雲存檔、跨玩家排行榜尚未上線**。

1. 建立 Supabase 專案，在 SQL Editor 執行 `supabase.sql`。
2. Authentication 啟用 Email OTP / Magic Link；設定 Site URL 為 `https://windzxy.github.io`，將 `https://windzxy.github.io/test/Game/pearl-tide/` 加入允許的 Redirect URLs。
3. 在遊戲「排行與雲端」中輸入專案 HTTPS URL 及 **publishable / anon key**（公開金鑰），點「連接後端」。絕對不要輸入 `service_role` key。
4. 輸入 Email 收取魔法登入連結，登入後按「上傳本地存檔」；其他裝置登入同一帳號後再按「讀取雲端存檔」。下載會覆蓋本機存檔，先匯出備份。
5. 輸入暱稱提交總營業收入，全球榜顯示前 20 名。

**安全說明：** RLS 可隔離不同玩家存檔，但目前成績由客戶端提交，仍可能篡改；排行榜僅為休閒展示，不能用於獎勵或正式競賽。正式版應讓可信伺服器執行購買、隨機開珠、製作和售賣，再從伺服器事件計算積分。遊戲不實作即時多人聊天；直播訊息為 NPC 模擬。
