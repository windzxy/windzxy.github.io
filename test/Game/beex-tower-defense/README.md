# 蜂巢古城守衛

蜂巢古城守衛是一個純前端、無第三方依賴的 HTML5 Canvas 塔防遊戲。畫面採用原創中國古代城防風格，關卡底圖使用 12 張高品質場景 WebP，塔、掉落和狀態圖標使用獨立圖片資源，不使用字母佔位。入口會預載場景 WebP，canvas 自身也有真實地圖背景；主程式啟動後直接使用場景圖中的敵營、我方城門和原生道路來生成敵人路線與投放平台。

## 玩法

- 在場景原本道路兩側投放不同類型的防禦設備，阻止敵人攻破蜂巢城門。
- 選中右側設備後，鼠標移到道路旁可放置位置才會亮出投放點；可點擊建造，也可把設備卡片拖到戰場投放。
- 每個主題都有 4 張完整場景底圖，並按關卡輪換裁切、光照和霧效變體；重開或進入下一主題後不再只是同一張簡單地圖。
- 每張場景都有獨立路線配置，敵營、城門和可投放區會跟著圖片裡的道路與建築走。
- 擊敗敵人可獲得更合理的糧草，用來建造、升級或拆除防禦塔。
- 每個主題共有 12 波敵人，第 4、8 波會出現 Boss，第 12 波是更難的終章大 Boss。
- 支援簡單、中等、困難三種難度預設，會影響敵軍血量、速度、數量、初始糧草、城防和戰功倍率。
- 目前包含古城山河、冰川寒原、火山熔境三個主題，天氣、敵軍強度和防禦設備表現會隨主題變化。
- 進入下一主題後周目提升，敵軍數量、血量、速度和密集度會繼續遞增。
- 建造設備會隨波次逐步開放，未解鎖前不會出現在建造卡片中。
- 低概率掉落「蜂鳴神弩」，點擊後可觸發全場齊射。
- 內建無依賴音效，可在戰令區切換音效/靜音。
- 支援玩家名字、本地排行榜、GitHub Issue 提交和 GitHub Action 寫入雲端排行榜。
- 支援暫停、倍速、重開、選中塔升級/拆除。
- 攻擊和減速效果使用蜂矢、冰蓮、雷印、爆裂等實體化圖形，不再只靠短線提示。

## 防禦塔

| 塔 | 特點 |
| --- | --- |
| 弩塔系 | 遠距離單體輸出，主題不同會變成神機弩、破冰弩或熔芯弩 |
| 控制系 | 減速控制，主題不同會變成寒玉蓮、霜晶蓮或灰燼蓮 |
| 連鎖系 | 連鎖傷害，主題不同會變成雷鼓臺、極光鼓或火山雷鼓 |
| 爆破系 | 第 7 波開放，使用獨立爆蜂罐素材，敵人接近時觸發範圍爆破 |
| 城防系 | 第 9 波開放，使用獨立蜂堡素材，定期修補城防並提供弱攻擊 |

## 文件

- `index.html` - 遊戲入口
- `styles.css` - 響應式界面與古代城防視覺
- `src/game.js` - 遊戲邏輯、場景底圖載入、原生道路路線、道路旁投放平台、難度、Boss、音效、交互
- `src/scenes.js` - 場景底圖清單，指向 12 張正常 WebP 圖片資源
- `src/scene-data/` - 舊版 data URI 場景備份，不再由入口阻塞載入
- `src/landmarks.js` - 舊版內嵌 PNG 地標備份；新版場景圖優先使用圖片內原生敵營與城門
- `src/sprites.js` - 內嵌高精度 PNG 塔與掉落素材，確保公開頁可直接載入新美術
- `assets/icons/` - 資源、城門、波次與操作 SVG 圖標
- `assets/map/` - 主題起點營地與終點城門 PNG
- `assets/towers/` - 高精度塔與蜂鳴神弩 PNG
- `assets/scenes/` - 古城、冰川、火山三大主題的完整關卡場景 WebP
- `assets/enemies/` - 透明敵軍 PNG
- `leaderboard.json` - GitHub Action 更新的排行榜資料
