# 蜂巢古城守卫

纯前端 HTML5 Canvas 塔防游戏，无第三方依赖。敌军沿场景原本道路进攻，玩家在道路两侧建造防御设备守住蜂巢城门。

## 入口

打开 `index.html` 即可游玩。

## 玩法

- 选择防御设备后，在道路旁可放置位置建造。
- 击败敌军获得粮草，用于建造、升级或拆除。
- 每个主题有多波敌袭与 Boss。
- 支持难度、倍速、暂停、重开和排行榜。

## 文件

- `index.html` - 游戏入口
- `styles.css` - 界面样式
- `src/game.js` - 游戏主逻辑
- `src/scenes.js` - 场景清单
- `assets/` - 图标、场景、敌军、防御塔与旗帜素材
