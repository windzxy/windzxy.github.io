# Maydayland Assets

本資料夾用於存放 Maydayland 後續補全素材。原則：

1. 優先使用官方可授權或可引用來源。
2. 不能確認權利的照片不直接入庫。
3. 暫無素材時使用資料檔中的 `pending` 狀態，不用低質假圖。
4. 可使用原創抽象城市圖、場館示意圖、票根/場刊占位圖作為過渡。

## 建議結構

```text
maydayland/assets/
  cities/        城市 Landing Page 主視覺
  venues/        場館外觀、入口、交通動線
  tickets/       票根、場刊、座位資訊
  posters/       巡演主視覺或原創替代海報
  exhibitions/   MAYDAYLAND 展區、城市裝置、拍照點
```

## 對應資料檔

- `data/asset-manifest-v37.json`：素材清單與目標路徑
- `data/venue-guides-v37.json`：場館攻略素材需求
- `data/city-landing-v37.json`：城市專題素材需求
