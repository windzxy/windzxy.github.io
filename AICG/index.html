EDITORIAL PIPELINE / 02

把 AICG 當成完整的視覺製作流程

不是「輸入一句話、輸出一張圖」。真正穩定的品質來自藝術方向、變體比較、機器審核與人工策展標準。

01

藝術方向

先定義情緒、鏡頭、色彩、光線、主體與負面限制，避免隨機抽卡式生成。

02

批次生成

同一方向生成多個候選，控制題材重複率，並維持每批視覺差異。

03

雙重審核

先做尺寸、解碼與安全檢查，再由視覺模型評估構圖、細節、原創性風險與桌布適用性。

04

策展發佈

只發布達標作品，輸出 WebP、縮略圖、描述與完整批次紀錄，交由 GitHub Pages 靜態展示。
